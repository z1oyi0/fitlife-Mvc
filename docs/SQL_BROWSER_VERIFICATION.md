## 測試範圍

使用真正的 SQL Server 容器，不以 SQLite 或記憶體資料庫代替。資料表依 C# 模型重建，不是學校原資料庫的備份；全程只使用人工建立的測試紀錄，未接觸學校或正式系統。測試帳密每次執行隨機產生，服務只綁定 runner 的 localhost，執行後移除容器。

瀏覽器以實際表單新增／編輯紀錄，再直接查詢 SQL Server 核對儲存結果。刪除與清單查詢也比對資料庫狀態。安全檢查另外使用未登入的獨立 HTTP 用戶端，沒有沿用登入 Cookie。

## 圖表截圖的補充驗證

第一輪以 Playwright `animations="disabled"` 截取整頁時，畫面中的圖表縮小；僅確認 dataset 與非空像素，不能直接宣稱截圖顯示完整。

因此在不修改程式或 CSS 的情況下，另比較三種取圖方式：

- `viewport-allow`：保留正常動畫，截取可見範圍。
- `fullpage-allow`：保留正常動畫，截取整頁。
- `fullpage-disabled`：停用動畫，截取整頁。

前兩種模式在截圖前後量得 canvas 顯示尺寸 1222 × 611，數值維持 180／260／320；實際檢視 `chart-fullpage-allow.png` 可見完整折線圖與資料表。停用動畫的整頁截圖再次出現壓縮／缺圖現象，截圖後亦測得尺寸變化。

因此，本次可支持「正常瀏覽器模式下的圖表、數值與整頁截圖已驗證」，但不把停用動畫的異常截圖當成正常成果。這是本次截圖模式的對照結果，沒有證明所有瀏覽器或裝置均無顯示問題，也未改動應用程式來配合截圖。

建議查看的實際檔案：`01-home.png`、`03-meal-list.png`、`04-meal-edit.png`、`05-query-pagination.png`、`chart-fullpage-allow.png`；`chart-visual-diagnostic.json` 保留尺寸、資料及未登入讀取的補充結果。

## 部署與安全結論

**沒有正式部署，也不宣稱完成全面安全性驗證。** 本次已發現未登入讀寫、防偽及輸入驗證等問題，應先修正，再重跑測試。正式上線還需要真實帳號與授權設計、最小權限資料庫帳號、HTTPS、正式環境設定、憑證輪換與保存、日誌／備份／回復及更廣的安全檢查。

本次沒有驗證原始 SQL Server 的連線與資料、手機／Firefox／WebKit、效能、多使用者隔離或所有攻擊情境；一般安全檢查通過與完整安全保證不是同一件事。
